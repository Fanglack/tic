# Tic-Tac-Toe game!
A simple two-player Tic Tac Toe game that runs in the terminal. Players take turns marking X and O on a 3×3 grid. The first player to get three symbols in a row, column, or diagonal wins.
Features
- Two-player gameplay.
- Interactive 3×3 game board.
- Win and draw detection.
- Input validation.
- Option to replay the game.
